### 8.2 第二次修复（2025-12-29 下午）- 颗粒度验证修复

#### 验证方法
使用 `2025.12.10/对应关系：MLS2511217004T_MLS2511217004N.result.xlsx` 与参考文档 `对应关系：苏雨起-乙状结肠癌-结直肠癌358基因+msi-mljy-lz258792-终版.docx` 进行颗粒度对比验证

#### 发现的问题
1. **CRC_IMPORTANT_GENES缺少SETD2** - 参考文档显示SETD2为关键突变基因(22.15%)
2. **IMMUNE_POSITIVE_GENES缺少TP53** - 参考文档显示TP53为免疫正相关基因
3. **非变异行被误识别** - Excel中包含注释/参考数据行（cHGVS列含癌症类型、Freq列含日期）

#### 修复内容
```python
# 1. CRC_IMPORTANT_GENES 新增 SETD2
CRC_IMPORTANT_GENES = {
    ...,
    "SETD2"  # 新增：参考文档显示SETD2为重要基因（22.15%突变率）
}

# 2. IMMUNE_POSITIVE_GENES 新增 TP53
IMMUNE_POSITIVE_GENES = {
    ...,
    "TP53"  # 新增：参考文档显示TP53为免疫正相关基因
}

# 3. build_variants_for_template() 新增cHGVS格式验证
c_hgvs = _norm_text(row.get("cHGVS"))
if not c_hgvs or not c_hgvs.startswith("c."):
    continue  # 跳过非变异行（如注释、参考数据等）
```

| 免疫正相关 | TP53, KRAS, ATM | TP53, KRAS, ATM | ✅ 匹配 |
| 全部真实变异 | 28个 | 28个 | ✅ 匹配 |
