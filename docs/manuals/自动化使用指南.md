# Excel到Docx自动化报告生成 - 使用指南

## 📋 概述

本系统实现了从Excel基因检测结果表自动生成标准化医疗报告的完整流程，无需手工录入数据。

## ✅ 系统验证状态

**系统状态**: ✅ 完全正常运行

**已验证功能**:
- ✅ Excel数据读取
- ✅ 字段自动映射（支持同义词）
- ✅ 数据清洗和验证
- ✅ Docx模板渲染
- ✅ 单个报告生成
- ✅ 批量报告生成

## 🚀 快速开始

### 方式1: 生成单个报告

```bash
python3 scripts/generate_report.py data/input/样本文件.xlsx
```

**示例**:
```bash
python3 scripts/generate_report.py data/input/MLF2509307001T_MLB2509307001.result.xlsx
```

### 方式2: 批量生成报告

```bash
python3 scripts/batch_generate_reports.py
```

这将自动处理 `data/input/` 目录下的所有Excel文件。

### 方式3: 自定义输入输出目录

```bash
# 单个报告
python3 scripts/generate_report.py <excel文件> <输出目录> <模板文件>

# 批量报告
python3 scripts/batch_generate_reports.py <输入目录> <输出目录> <模板文件>
```

## 🔧 系统工作原理

### 数据流程

```
Excel文件
    ↓
[1] ExcelReader: 读取所有Sheets数据
    ↓
[2] FieldMapper: 根据mapping.yaml进行字段映射
    ↓
[3] DataCleaner: 清洗和验证数据
    ↓
[4] TemplateRenderer: 使用Jinja2渲染Docx模板
    ↓
终版报告.docx
```

### 字段映射机制

系统使用**同义词匹配**自动识别Excel列名：

```yaml
# config/mapping.yaml
patient_name:
  synonyms: ['患者姓名', '姓名', '病人姓名', '患者名']
  ↓
无论Excel用哪个列名，都能自动识别
```

### 表格数据处理

```yaml
# Excel Variations表（131行）自动映射到模板
variants:
  sheet_name: Variations
  columns:
    gene: ['Gene_Symbol', '基因']
    variant: ['cHGVS', '变异位点']
    ...
↓
模板中使用 {% for row in variants %} 自动展开
```

## 📝 输出文件命名

自动生成的报告文件名格式：
```
{患者姓名}-{疾病类型}-{项目名称}-{样本编号}-终版.docx
```

**示例**:
```
张三-结肠癌-结直肠癌358基因检测-MLB2509307001-终版.docx
```

## ⚙️ 配置说明

### 1. 字段映射配置 (config/mapping.yaml)

定义Excel列名到模板变量的映射关系：

```yaml
single_values:  # 单值字段
  patient_name:
    synonyms: ['患者姓名', '姓名']
    type: string
    required: true

table_data:  # 表格数据
  variants:
    sheet_name: Variations
    columns:
      gene:
        synonyms: ['Gene_Symbol', '基因']
```

### 2. 患者信息库 (config/patient_info.yaml)

存储患者基本信息，通过样本编号自动匹配：

```yaml
MLB2509307001:
  patient_name: 张三
  gender: 男
  age: 45
  hospital: 某某医院
```

### 3. 模板文件 (templates/aligned_template_final.docx) ⭐

**重要**: 生产环境使用 `aligned_template_final.docx`（7.38 MB完整模板）

使用Jinja2语法的Docx模板：

```jinja2
患者姓名: {{ patient_name }}
样本编号: {{ sample_id }}
TMB值: {{ tmb_value }} {{ tmb_unit }}
MSI状态: {{ msi_status }}

{% for row in variants %}
  {{ row.Gene_Symbol }} | {{ row.cHGVS }} | ...
{% endfor %}
```

## 🔍 故障排除

### 问题1: 缺少依赖包

```bash
pip install --break-system-packages docxtpl pandas openpyxl PyYAML python-dateutil click
```

### 问题2: 模板文件路径错误

确保模板文件存在：
```bash
ls -l templates/aligned_template.docx
```

### 问题3: Excel文件格式不支持

- ✅ 支持: `.xlsx` 格式
- ❌ 不支持: `.xls` (旧格式)

转换方法:
```bash
# 使用LibreOffice转换
soffice --headless --convert-to xlsx old_file.xls
```

### 问题4: 字段映射失败

检查Excel列名是否在同义词列表中：
```bash
# 查看mapping.yaml中的同义词配置
cat config/mapping.yaml | grep -A 3 "patient_name"
```

如需添加新的同义词，编辑 `config/mapping.yaml`。
