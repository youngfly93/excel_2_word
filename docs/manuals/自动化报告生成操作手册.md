## 1. 系统概述

### 1.1 功能简介

本系统可以**自动**从Excel检测结果文件生成标准化的Word医学报告，实现：

- ✅ **自动读取**Excel各sheet的检测数据（Variations、CNV、Fusion、HLA、TMB、MSI等）
- ✅ **智能过滤**变异数据（频率阈值、临床显著性筛选）
- ✅ **自动填充**患者信息、检测结果到Word模板
- ✅ **动态生成**表格（变异明细、药物推荐、CNV、Fusion、HLA等）
- ✅ **批量处理**多个样本

### 1.2 系统架构

```
Excel文件 → 数据读取 → 字段映射 → 数据清洗 → 模板渲染 → Word报告
             ↓           ↓          ↓          ↓
          解析各sheet  mapping.yaml  过滤器  Jinja2模板
```

### 1.3 技术栈

- **Python 3.9+**
- **核心库**: docxtpl (模板引擎)、pandas (数据处理)、openpyxl (Excel读取)
- **配置**: YAML格式配置文件

## 4. 详细操作步骤

### 4.1 准备Excel数据文件

#### 必需的Excel结构

Excel文件必须包含以下sheet（按优先级）：

| Sheet名称 | 是否必需 | 说明 |
|-----------|---------|------|
| QC | 推荐 | 质控数据 |
| Variations | **必需** | 变异明细（系统会自动过滤） |
| TMB | **必需** | 肿瘤突变负荷 |
| Msisensor | **必需** | 微卫星不稳定性 |
| HLA | 可选 | HLA分型结果 |
| Cnv | 可选 | 拷贝数变异 |
| Fusion | 可选 | 融合基因 |
| CtDrug | 可选 | 药物-基因型关系（1100行药物库） |

#### Excel文件命名规范

```
格式: <任意前缀>_<样本编号>.result.xlsx
示例: data/input/MLF2509307001T_MLB2509307001.result.xlsx
      ^^^^^^^^^^^^^^^^ ^^^^^^^^^^^^^^
      项目编号          样本编号（会自动提取）
```

**重要**: 系统会从文件名中自动提取样本编号（`MLB2509307001`部分），用于匹配`patient_info.yaml`中的患者信息。

### 4.2 配置患者信息（可选）

如果Excel中缺少患者信息，可以在`config/patient_info.yaml`中预先配置：

```yaml

  department: "肿瘤科"
```

**注意**: Excel中的数据优先级高于patient_info.yaml。

### 4.3 选择正确的模板文件

系统提供多个模板，根据需求选择：

| 模板文件 | 说明 | 推荐使用 |
|---------|------|---------|
| `aligned_template_with_cnv_fusion_hla_FIXED.docx` | **最新修复版**，包含CNV、Fusion、HLA表，药物表已修复 | ✅ **推荐** |

## 5. 配置文件说明

### 5.1 核心配置文件结构

```
config/
├── mapping.yaml           # 字段映射配置（核心）
├── filtering.yaml         # 数据过滤规则
├── patient_info.yaml      # 患者信息库
├── project_types.yaml     # 项目类型自动识别
└── settings.yaml          # 全局设置
```

### 5.2 mapping.yaml - 字段映射配置

**作用**: 定义Excel列名到模板变量的映射关系

#### 单值字段映射示例

```yaml
single_values:
  patient_name:
    synonyms: ["患者姓名", "姓名", "病人姓名"]  # Excel可能使用的列名
    type: string
    required: true
    description: "患者姓名，必填字段"

  tmb_value:
    synonyms: ["TMB值", "TMB", "Tumor Mutation Burden"]
    type: float
    required: false
    format_template: "{:.2f}"  # 保留2位小数
```

#### 表格数据映射示例

```yaml
table_data:
  variants:  # 模板中的变量名: {% for row in variants %}
    sheet_name: "Variations"  # Excel中的sheet名
    required: false
    empty_behavior: "show_placeholder"
    columns:
      gene:
        synonyms: ["基因", "Gene", "Gene_Symbol"]
        type: string

      transcript:
        synonyms: ["Transcript", "转录本"]
        type: string

      # ... 更多列定义
```

### 5.3 filtering.yaml - 过滤规则配置

**作用**: 控制哪些变异数据被保留到报告中

#### 变异过滤配置

```yaml
variations:
  enabled: true  # 是否启用过滤

  # 频率过滤
  frequency_filter:
    enabled: true
    min_frequency: 5.0  # 阈值：5% (可调整)
    frequency_columns: ["Freq(%)", "AF", "变异频率"]

  # 临床显著性过滤
  clinical_significance_filter:
    enabled: true
    significant_keywords:  # 保留这些类型的突变
      - "Missense"      # 错义突变
      - "Nonsense"      # 无义突变
      - "Frameshift"    # 移码突变
      - "Splice"        # 剪接位点
      - "CDS-indel"     # 编码区插入缺失
```

#### 过滤逻辑

```
保留条件 = (频率 >= 5%) OR (突变类型为临床显著)
```

**示例**:
- 频率 8%，Missense → ✅ 保留（满足条件1）
- 频率 2%，Nonsense → ✅ 保留（满足条件2）
- 频率 2%，Synonymous → ❌ 过滤掉（两个条件都不满足）

#### 调整过滤阈值

```bash
# 编辑配置文件
vi config/filtering.yaml

# 修改频率阈值（例如改为3%）
min_frequency: 3.0

# 保存后重新生成报告，行数会增加
```

### 5.4 patient_info.yaml - 患者信息配置

**作用**: 预先配置患者信息，避免每次手动输入

```yaml
# 格式：样本编号: {字段: 值}
```

**使用方式**: 系统会自动从Excel文件名提取样本编号，匹配对应的患者信息。

### 6.2 变异表数据流详解

#### Step 1: Excel读取（131行原始数据）

```python
# Variations sheet: 131 rows
Gene_Symbol | Transcript   | Chr  | cHGVS      | Function  | Freq(%)
------------------------------------------------------------------------
ARID1A      | NM_006015.6  | chr1 | c.3991C>T  | Nonsense  | 0.68
JAK1        | NM_002227.4  | chr1 | c.656G>A   | Missense  | 0.55
...         | ...          | ...  | ...        | ...       | ...
```

#### Step 2: 过滤（56行通过过滤器）

```python
# 应用filtering.yaml规则
- 频率 >= 5%: 6 rows
- 临床显著突变类型: 58 rows
- 合并（OR逻辑）: 56 rows
```

#### Step 3: 字段映射（56行 → 报告数据）

```python
# mapping.yaml: variants表的列映射
Gene_Symbol → {{ row.Gene_Symbol }}
Transcript  → {{ row.Transcript }}
Chr         → {{ row.Chr }}
cHGVS       → {{ row.cHGVS }}
Function    → {{ row.Function }}
Freq(%)     → {{ row['Freq(%)'] }}
Drug        → {{ row.Drug }}
```

#### Step 4: 模板渲染（生成Word表格）

```jinja2
{# Template Table 3, Row 2 #}
{% for row in variants %}
<w:tr>
  <w:tc>{{ row.Gene_Symbol }}</w:tc>      {# Cell 0: 基因名 #}
  <w:tc>{{ row.Transcript }}</w:tc>       {# Cell 1: 转录本 #}
  <w:tc>{{ row.Chr }}</w:tc>              {# Cell 2: 染色体 #}
  <w:tc>{{ row.ExIn_ID }}</w:tc>          {# Cell 3: 外显子 #}
  <w:tc>{{ row.cHGVS }}</w:tc>            {# Cell 4: 位点 #}
  <w:tc>{{ row.Function }}</w:tc>         {# Cell 5: 突变类型 #}
  <w:tc>{{ row['Freq(%)'] }}</w:tc>       {# Cell 6: 频率 #}
  <w:tc>{{ row.Drug }}</w:tc>             {# Cell 7: 药物 #}
  <w:tc>--</w:tc>                         {# Cell 8: 耐药药物 #}
</w:tr>
{% endfor %}
```

**结果**: Word文档中的Table 3包含56行变异数据，每行9列。

## 7. 常见问题FAQ

### Q1: 生成的报告中药物列显示"*"而不是药物名称？

**原因**: Excel的Variations sheet中Drug列就是"`*`"，没有实际药物数据。

**解决方案**:
- **短期**: 这是正常现象，"`*`"表示该变异有潜在药物关联但未在Variations表中详细列出
- **长期**: 需要集成CtDrug sheet（1100行药物库）或外部药物知识库

### Q2: 生成的报告表格行数和参考文档不一致？

**回答**: 这是**正常且预期**的行为！

- **参考文档**: 31行（人工精选的重要基因列表）
- **自动生成**: 56行（所有符合过滤条件的变异）
- **原因**: 自动生成是基于Excel实际数据+过滤规则，行数会动态变化

**如何调整**:
1. 修改`config/filtering.yaml`中的阈值
2. 提高`min_frequency`（如改为10%）会减少行数
3. 移除某些临床显著性关键词也会减少行数

### Q3: 提示"缺失必填字段: report_date"？

**原因**: Excel中没有"出报告日期"列，且patient_info.yaml中也没有配置。

**解决方案**:

**方法1**: 在Excel的QC sheet添加"出报告日期"列

**方法2**: 在`config/patient_info.yaml`中添加：

```yaml
MLB2509307001:
  report_date: "2025-11-18"  # 添加这一行
  # ... 其他字段
```

**方法3**: 修改`config/mapping.yaml`，将report_date设为非必填：

```yaml
single_values:
  report_date:
    required: false  # 改为false
```

### Q4: HLA表没有数据或显示错误？

**检查清单**:
1. Excel中是否有HLA sheet
2. HLA sheet的结构是否正确（3个locus，每个locus有Type1/Type2和QC数据）
3. 模板是否是修复版（`aligned_template_with_cnv_fusion_hla_FIXED.docx`）

### Q5: 如何批量处理多个样本？

见 [9.1 批量生成报告](#91-批量生成报告)

### Q6: 生成速度慢怎么办？

**优化建议**:
1. 减少Excel文件大小（删除不必要的sheet）
2. 提高过滤阈值（减少保留的变异数量）
3. 使用SSD硬盘
4. 关闭不必要的后台程序

**正常耗时参考**:
- 单个样本: 5-10秒
- 批量50个样本: 5-8分钟

### 8.2 常见错误及解决方案

#### 错误1: `FileNotFoundError: Excel文件不存在`

```
FileNotFoundError: [Errno 2] No such file or directory: 'xxx.xlsx'
```

**解决**:
- 检查Excel文件路径是否正确
- 使用绝对路径或确认当前工作目录
- 检查文件名拼写

#### 错误2: `ValueError: Sheet 'Variations' not found`

```
ValueError: Sheet 'Variations' not found in Excel file
```

**解决**:
- 打开Excel检查是否有Variations sheet
- 检查sheet名称大小写（区分大小写）
- 确认sheet没有被隐藏

#### 错误3: `TemplateError: {{ row.xxx }} 未定义`

```
jinja2.exceptions.UndefinedError: 'row' has no attribute 'xxx'
```

**解决**:
- 检查模板中使用的字段名是否在mapping.yaml中定义
- 检查Excel列名是否匹配mapping.yaml中的synonyms
- 使用最新的修复版模板

#### 错误4: 生成的文档打开提示"文件损坏"

**原因**: 模板文件本身有问题或渲染过程出错

**解决**:
1. 使用官方提供的修复版模板
2. 检查模板文件是否完整（文件大小应该>7MB）
3. 尝试用LibreOffice打开查看详细错误

#### Step 2: 创建基因-药物映射

在`reportgen/core/field_mapper.py`中添加方法：

```python
def _build_gene_drug_mapping(self, excel_data):
    """从CtDrug sheet构建基因-药物映射"""
    ctdrug_data = excel_data.get_table_data("CtDrug")
    if not ctdrug_data:
        return {}

    # 构建映射: gene -> [{drug, genotype, benefit}]
    gene_drug_map = {}
    for row in ctdrug_data:
        gene = row.get("检测基因")
        drug = row.get("药物")
        benefit = row.get("用药提示（仅供参考）")

        if gene and drug:
            if gene not in gene_drug_map:
                gene_drug_map[gene] = []
            gene_drug_map[gene].append({
                "drug": drug,
                "benefit": benefit
            })

    return gene_drug_map
```

#### Step 3: 在variants映射中应用

```python
def _map_tables(self, excel_data, report_data):
    # 构建药物映射
    gene_drug_map = self._build_gene_drug_mapping(excel_data)

    # 映射variants表时，关联药物信息
    for row in variants_data:
        gene = row.get("Gene_Symbol")
        if gene in gene_drug_map:
            drugs = gene_drug_map[gene]
            row["benefit_drugs"] = ", ".join([d["drug"] for d in drugs[:3]])  # 取前3个
```
