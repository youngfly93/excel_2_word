# 自动化报告生成 - 快速参考卡

**最后更新**: 2025-11-18

---

## 🚀 最常用命令

### 生成单个报告
```bash
python3 -m reportgen.cli generate \
  --excel data/input/MLF2509307001T_MLB2509307001.result.xlsx \
  --template templates/aligned_template_with_cnv_fusion_hla_FIXED.docx \
  --output data/output/
```

---

## 📁 关键文件位置

| 文件 | 路径 | 说明 |
|------|------|------|
| **推荐模板** | `templates/aligned_template_with_cnv_fusion_hla_FIXED.docx` | ✅ 最新修复版 |
| **过滤配置** | `config/filtering.yaml` | 调整频率阈值 |
| **患者信息** | `config/patient_info.yaml` | 预配置患者数据 |
| **输入Excel** | `data/input/` | 放置Excel文件 |
| **生成报告** | `data/output/` | 查看生成结果 |

---

## ⚙️ 常用配置调整

### 修改频率阈值（更多/更少变异）

```bash
vi config/filtering.yaml

# 修改这一行:
min_frequency: 5.0  # 改为3.0（更多）或10.0（更少）
```

### 添加患者信息

```bash
vi config/patient_info.yaml

# 添加:
MLB2509307002:
  patient_name: "李四"
  age: 58
  gender: "女"
```

## 🔍 验证检查清单

生成报告后检查：

- [ ] 患者姓名、年龄、性别正确
- [ ] TMB值显示（如 7.56 Muts/Mb）
- [ ] MSI状态显示（如 MSS）
- [ ] 变异表Cell[1]是转录本号（如NM_006015.6），**不是**基因名
- [ ] 变异表行数合理（通常30-100行）
- [ ] 没有空表格

---

## 🐛 快速故障排查

| 问题 | 解决方案 |
|------|---------|
| 提示Excel文件不存在 | 检查路径，使用绝对路径 |
| 提示Sheet 'Variations' not found | 检查Excel中sheet名称大小写 |
| 缺失必填字段report_date | 在patient_info.yaml添加或改为非必填 |
| 药物列显示"*" | 正常，当前Excel没有详细药物数据 |
| 转录本列显示基因名 | 使用FIXED版本模板 |

## 📊 数据流向（一图了解）

```
Excel → 读取 → 过滤 → 映射 → 渲染 → Word报告
  ↓      ↓      ↓      ↓      ↓
131行  131行  56行  56行  Table 3有56行
```

**关键**: 表格行数是**动态的**，根据Excel数据和过滤规则自动计算！
