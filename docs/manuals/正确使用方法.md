## 🔧 工作原理

### 1. 模板变量

`aligned_template_final.docx` 包含Jinja2变量：

```jinja2
【单值字段】
{{ patient_name }}          患者姓名
{{ sample_id }}             样本编号
{{ tmb_value }}             TMB值
{{ msi_status }}            MSI状态

【表格循环】
{% for row in variants %}
  {{ row.Gene_Symbol }}     基因名称
  {{ row.cHGVS }}          变异位点
  {{ row.Function }}        功能影响
{% endfor %}

{% for row in chemotherapy %}
  {{ row.药物 }}            药物名称
  {{ row.检测基因 }}        相关基因
{% endfor %}
```

### 2. 数据流程

```
Excel结果文件 (MLF*.result.xlsx)
    ↓
[1] ExcelReader: 读取12个Sheets
    ↓
[2] FieldMapper: 字段映射（保留原始列名）
    ↓
[3] DataCleaner: 数据清洗
    ↓
[4] TemplateRenderer: Jinja2渲染
    ↓
aligned_template_final.docx (模板)
    ↓
终版.docx (7.4 MB完整报告)
```

### 3. 关键修复

**表格数据渲染修复** (2025-11-17):
- 修改了 `reportgen/models/mapping.py` 的 `map_row()` 方法
- 保留原始Excel列名（如 `Gene_Symbol`）而不是标准化名称（如 `gene`）
- 确保模板变量能正确访问表格数据

## 🔍 故障排除

### 问题1: 生成的文件太小（< 1 MB）

**原因**: 使用了错误的模板（aligned_template.docx）

**解决**:
```bash

python3 scripts/generate_report.py <excel> data/output templates/aligned_template_final.docx
```

### 问题2: 表格没有数据

**原因**: FieldMapper字段名映射问题（已修复）

**验证**:
