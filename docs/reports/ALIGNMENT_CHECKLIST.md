- 终版报告: `王卫星-降结肠癌-结直肠癌301基因+msi-mljy-lz258074-终版.docx`
- 详情参见: `COMPARISON_DETAILED.md`

目标：仅变量区域（如患者信息值、变异表明细等）可变，所有静态文本、表头、版式尽量与终版一致。

## 页面与分节
- A4 页面尺寸：21.0 x 29.7 cm（portrait）。
- 分节数：5 节；依序：封面 → 导读/声明 → 目录 → 正文 → 附录。
- 边距：前4节 L3.175 R3.175 T2.54 B2.54 cm；最后一节 L1.27 R1.27 T1.27 B1.27 cm。
- 页眉/页脚：拷贝终版的固定文本与样式（页码/横线/Logo如有）。

## 固定段落与标题（逐字对齐）
请将模板中的以下固定文案与终版一致（标点、空格、换行均保持）：
- “检测报告”（封面）
- “报告导读” 与 4段说明文字
- “咨询电话：022-87190699。”
- “致您的一封信”
- “目    录”（注意对齐空格）
- “第一部分：基本信息” → “患者信息” → 附注文案
- “检测内容”
- “第二部分：检测结果” 各小节标题
- “第三部分：基因变异及相应靶向/免疫药物解析” 及阅读说明
- “第四部分：附录” 与声明/文献等固定说明

建议操作：打开终版报告，复制上述段落至模板对应位置，并设定一致的段落样式和对齐方式。

## 表格结构与表头（列数/文字一致）
请在模板中建立以下表格骨架（用于后续变量填充）：
- 患者基本信息表（4行×5列样式，含：姓名、性别、年龄、样本类型、病理编号、送检医院、科室、临床诊断等）。
- 靶向治疗药物提示表：
  - 表头：`基因 | 突变位点 | 潜在获益靶向药物 （证据等级） | 可能耐药或慎重药物 （证据等级）`
- TMB/MSI/其它生物标志物结果表：
  - 表头：`TMB/MSI/其它生物标志物检测结果 | TMB/MSI/其它生物标志物检测结果 | 用药提示`
- 化疗药物检测结果表：
  - 表头：`化疗药物检测结果`
- 基因变异明细表（宽表）：
  - 表头示例：`基因名称 | 基因突变信息 | 基因突变信息 | 基因突变信息 | 基因突变信息 | 基因突变信息 | 基因突变信息 | 靶向药物信息 | 靶向药物信息`（与终版列数一致）
- 药物解析/基因解析等附表：表头与列名与终版一致。

注意：
- 保持表格数量与顺序与终版一致。
- 表头文本逐字一致；列数相同（即使某些列暂时留空占位）。

## 变量与占位符（建议命名）
结合现有映射（config/mapping.yaml），在模板中放置 Jinja2 占位符：
- 单值：
  - `{{ patient_name }}`、`{{ gender }}`、`{{ age }}`、`{{ pathology_id }}`
  - `{{ hospital }}`、`{{ department }}`、`{{ project_info.project_name }}`
  - `{{ sample_id }}`、`{{ report_date }}`
  - 生物标志物：`{{ TMB }}`、`{{ MSI状态 }}`
- 表格：
  - 变异明细：
    ```
    {% for row in variants %}
    {{ row.Gene_Symbol }} | {{ row.cHGVS }} | {{ row.pHGVS_S or row.pHGVS_A }} | {{ row['Freq(%)'] }} | ...
    {% endfor %}
    ```
  - 化疗药物：`{% for row in chemotherapy %} ... {% endfor %}`
  - 其它数据表依 mapping.yaml 的表名与列别名设置。

## 样式与版式
- 标题样式：与终版相同的字号、加粗、行距、居中/两端对齐。
- 表格样式：边框线型、表头底色/加粗、单元格内边距与间距一致。
- 目录页：如终版有自动目录，模板中保留静态目录文本并与页码对齐（变量区域不含页码）。

## 不可变区域说明
- 报告中的所有固定文案、表头、版式均视为不可变区域。
- 仅数据值与表格行内容为可变（由系统填充）。
- 模板中可通过注释或高亮标注“变量区域”以避免误改。

## 最后验收（对齐核对）
- 段落数/分节数大致匹配（允许变量导致段落微增减）。
- 表格数与顺序一致；表头逐字一致；列数一致。
- 页眉/页脚与页码样式一致。
- 封面/导读/目录/正文/附录标题与文案一致。
