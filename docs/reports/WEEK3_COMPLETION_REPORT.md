### 2.2 配置加载器增强 ✅

**文件**: `reportgen/config/loader.py`

**新增方法**: `load_patient_info()`

**关键代码**:
```python
def load_patient_info(self, sample_id: Optional[str] = None) -> Dict[str, Any]:
    """加载患者信息配置"""
    config = self.load_yaml(str(patient_info_file))
    
    # 先加载默认值
    defaults = config.get("defaults", {})
    project_info = config.get("project_info", {})
    result = {**defaults, **project_info}
    
    # 匹配特定患者信息
    if sample_id:
        patients = config.get("patients", {})
        patient_data = patients.get(sample_id)
        if patient_data:
            result.update(patient_data)
    
    return result
```

**特性**:
- ✅ 支持样本编号匹配
- ✅ 支持默认值fallback
- ✅ 完整的日志记录
- ✅ 错误处理
